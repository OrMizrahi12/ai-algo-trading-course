# Student kit: Lesson 1.1, What you will build

Module 1: Welcome · AI Algorithmic Trading with Claude Code and Interactive Brokers

In this lesson you toured the finished Trading Lab, the project you build in this course: the strategy factory and
its leaderboard, a strategy running live on a paper account, the AI desk deciding on every 5-minute bar, its memory
in Obsidian, and the dashboard. Then you saw how the 16 modules get you there, what you need, and how to use the
student kits.

Everything in this course runs on a paper (simulated) account. It is educational content, not financial advice, and
nothing shown is a promise of profit: the course teaches the method and the tools.

## What's in this kit

| File | What it is |
|---|---|
| `course-map.md` | All 16 modules and their lessons, in order, with what each part builds |
| `setup-checklist.md` | What you need before you start: a computer, a Claude plan, an Interactive Brokers account used on paper |
| `how-to-use-the-kits.md` | How every student kit is laid out, and how to work through a lesson with it |

## Try it yourself (the pause-and-try checkpoint)

1. Open `setup-checklist.md` and tick what you already have.
2. Choose a Claude plan: Pro is enough to start. Lesson 3.2 shows the plans and the install.
3. Start your Interactive Brokers account if you don't have one yet. Lesson 2.1 walks through it, and every account
   comes with a paper account.
4. Skim `course-map.md` and find the lesson where each part of the tour is built.

You're done when every line of `setup-checklist.md` has an answer, and you know which lesson builds each of the five
parts of the lab.

## Good to know

- **Free data.** The course runs on the data every Interactive Brokers paper account gets for free: price history
  and 15-minute delayed quotes. Real-time data is an optional paid add-on, never required.
- **No API key.** Claude runs on your Pro or Max subscription. You never need an Anthropic API key.
- **Your results will differ.** The lab you build will find different things from ours, and Claude's answers will
  be worded differently. That's expected, and it's the point.
- Plans, prices and versions shown in the course were current when it was recorded (October 2026).
