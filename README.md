# AI Algorithmic Trading with Claude Code and Interactive Brokers: course materials

The learner files for the course, one folder per lesson: worksheets, checklists, the exact prompts shown on screen,
and, from module 3 on, the code of the running project.

| Folder | What it holds |
|---|---|
| `lessons/<module>.<lesson>/` | The files for that lesson, with a short README |

Everything in this course runs on a paper (simulated) account. It is educational content, not financial advice, and
no strategy here is presented as profitable. Read your AI provider's and your broker's terms; any real-money decision
is yours alone.
